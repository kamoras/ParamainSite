# Security Policy

## Reporting a vulnerability

We take security seriously across every Paramain project. If you believe you've
found a security vulnerability in this site (or any Paramain app), please report
it responsibly.

**Please do _not_ open a public issue for security problems.**

Instead, email **[mack.ryanm@gmail.com](mailto:mack.ryanm@gmail.com)** with:

- A description of the issue and its potential impact
- Steps to reproduce
- Any relevant logs, screenshots, or proof-of-concept

You can expect an acknowledgement within **72 hours**, and we'll keep you posted
as we work on a fix. We're grateful for responsible disclosure and happy to
credit you once the issue is resolved (unless you'd prefer to stay anonymous).

## Supported versions

This is a continuously deployed site; the `main` branch is always the supported
version.
